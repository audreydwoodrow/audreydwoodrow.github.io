Ski Day Rating Predictor

Python · PyTorch · pandas · NumPy

I wanted to understand what is actually happening inside a neural network, not just call one.

Predicts how highly a skier rates a hypothetical ski day from eight conditions: lift wait, ticket price, temperature, share of slopes open, weather, wind, weekday, and vacation week. Trained on 6,490 ratings from 375 skiers in a published conjoint survey, with a command-line tool for running any scenario.

Decisions

  • Worked a linear model out by hand before writing the ReLU network, so I could check the code against something I had already derived myself. Slower, but I understood every number.
  • Split the data by skier rather than by response, so one person's ratings could never land on both sides of the train and test line.
  • Kept the test set closed through every experiment and opened it exactly once, at the end.
  • Published an R-squared of 0.12 instead of a flattering number. Conditions explain part of why someone rates a ski day, not most of it, and the write-up says so plainly.

Canvas Course Dashboard

Python · Flask · SQLite · JavaScript · Canvas LMS REST API

I wanted all of my deadlines in one place, including the ones that have nothing to do with class.

Authenticates against the Canvas API and pulls assignments, deadlines, and announcements from every enrolled course into a single calendar, next to a weekly task board and my own recurring events.

Decisions

  • Looked hard at integrating directly with university grade portals and turned it down. The security surface and the complexity were not worth what it added, so scores and class medians are entered by hand instead.
  • Added a class median field next to every grade. Medians almost always turn up somewhere else, in an email or a separate announcement, and I wanted to read mine next to the score instead of going looking for it.
  • The access token is checked against the Canvas API before it is saved, so a typo fails immediately instead of silently returning nothing.
  • Everything stays on the machine it runs on: a local SQLite file, a local config file, and a server bound to localhost only.

Closet Stylist

JavaScript · Node · Anthropic API

I wanted to find out whether a model could be useful at something subjective, and fashion was the version of that problem I actually had.

Upload an inspiration photo and it suggests outfits from clothes you already own and have tagged yourself. Built on the Anthropic API, partly to learn how image models handle something this fuzzy. It solves a real problem of mine, and it is just really cool when it works.

Decisions

  • Tagging stays manual. The model suggests combinations; it does not get to decide what I own or what things are.
  • Shows a cost estimate before every call and defaults to the cheapest model, because it is far too easy to build something that quietly spends money.
  • Sends only the filtered subset of the closet a match actually needs, rather than everything.
  • Photos and tags live as plain files on disk, so the whole thing can be read, backed up, or deleted without my permission being involved.
